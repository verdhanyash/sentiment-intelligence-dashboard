**Nuance API – Complete AWS Cost Analysis, Pricing Strategy & Profitability**

I've reviewed our AWS expenditure and current GPU processing estimates. Based on the available data, here's how we can structure the API business, decide our selling price and offer free usage without creating unnecessary losses.

### 1. Current AWS Infrastructure & Processing Cost

Our current GPU instance cost is approximately ₹172.50/hour.

Based on the assumption that GPU processing time is equal to video duration:

- Cost per GPU second: ₹0.0479
- Cost per 1-minute video: ₹2.875
- Cost per 2-minute video: ₹5.75
- Cost per 5-minute video: ₹14.37

If we add an estimated 40% operational overhead for retries, failed requests, storage, moderation and other operational expenses, our estimated loaded cost becomes approximately ₹4.03 per video minute.

Important: This is a working estimate, not our verified all-in cost. We still need actual inference telemetry and attributable AWS billing data.

### 5. Individual AI Model Cost Structure

Our current Nuance architecture contains five major components:

1. Whisper – Speech-to-text transcription.
2. BERT – Text processing and classification.
3. Video Encoder – Extracts visual information.
4. Audio Encoder – Extracts audio features.
5. Fusion Layer – Combines information from different modalities.

AWS currently bills the shared SageMaker endpoint rather than providing a separate bill for each model.

However, we can calculate the internal cost allocation using telemetry.py, which records execution timings for individual stages.

Formula:

Model GPU cost = GPU execution seconds × ₹0.0479.

Once we have actual telemetry, we can introduce separate API endpoints and pricing for individual models.

This also gives us the opportunity to sell transcription-only, audio-only, video-only and complete multimodal analysis separately, provided the architecture supports independent execution.

### 6. AWS Infrastructure & Scaling

Our latest AWS console snapshot shows:

- November MTD expenditure: approximately ₹11,000.
- AWS month-end forecast: approximately ₹24,330.
- Average daily gross expenditure in the earlier audit: ₹733.38.
- SageMaker accounts for approximately 99.7% of the displayed service spending.

A continuously running GPU endpoint at ₹172.50/hour would cost approximately ₹1,25,925/month over 730 hours.

This is why we should not keep the GPU running 24/7 unnecessarily.

We should prioritize:
- On-demand inference or scale-to-zero where supported.
- Autoscaling based on incoming requests.
- Monitoring idle GPU time.
- Batching requests where appropriate.
- Tracking GPU utilization and inference duration.
- Optimizing model execution and memory consumption.

The theoretical always-on cost allocated per video is approximately:
- 19 videos/day: ₹218/video.
- 100 videos/day: ₹41.40/video.
- 1,000 videos/day: ₹4.14/video.

This demonstrates why infrastructure utilization is extremely important.

However, the 400–500 daily-minute break-even estimate needs validation against actual request volume, provisioned capacity, and on-demand infrastructure costs. It is not a guaranteed universal threshold.

### 8. Important Business & Technical Decisions

Before launching commercially, we should:

- Measure actual GPU execution time instead of assuming it equals video duration.
- Calculate individual model costs through telemetry.
- Track successful requests, failed requests and retries.
- Implement API key management and per-account usage tracking.
- Introduce monthly credit limits and overage billing.
- Prevent free-credit abuse through account verification.
- Set maximum video duration, request size and concurrency limits.
- Introduce dedicated infrastructure pricing for enterprise customers.
- Track actual AWS cost per successful processed video minute.

We should also account for applicable privacy and AI regulatory requirements, especially when selling emotion-related analysis for workplace or educational use.
